# 自主課題スプレッドシート AI採点

模範解答がない、自由制作・データ分析・グラフ作成などのGoogleスプレッドシート課題を、課題指示と採点基準に基づいてGeminiで評価するGoogle Apps Scriptです。

以前の数式完全一致型オートグレーダーとは別のプロジェクトです。Classroom APIは使用せず、Google ClassroomがDriveに作成した提出物フォルダを走査します。

## 採点の流れ

1. 先生が提出物フォルダURLを設定します。
2. 課題の指示、配布データ、採点基準を文章またはURLで設定します。
3. 採点するシート名だけを指定します。
4. フォルダ内の提出スプレッドシートを自動取得します。
5. 指定シートの値、R1C1数式、グラフ概要を抽出します。
6. Geminiが採点基準に沿って各答案を10点満点で評価します。
7. 提出物フォルダ内に新しい採点結果スプレッドシートを作成します。

ファイル名を生徒答案のインデックスとして使用します。

## 必要なもの

- GoogleスプレッドシートとGoogle Driveを操作できるGoogleアカウント
- [Google AI Studio](https://aistudio.google.com/apikey)で発行したGemini APIキー
- 提出物フォルダと提出ファイルを閲覧できる権限

Gemini APIの利用量に応じて料金や利用上限が発生する場合があります。

## 導入

1. AI採点管理用のGoogleスプレッドシートを新しく作成します。
2. `拡張機能 > Apps Script` を開きます。
3. `OpenEndedGrader.gs` の内容を貼り付けて保存します。
4. 管理用スプレッドシートを再読み込みします。
5. `自主課題AI採点 > 初期設定シートを作成` を実行します。
6. `自主課題AI採点 > Gemini APIキーを保存` を実行します。

APIキーは設定シートには書かれず、実行ユーザーのApps Scriptプロパティに保存されます。

## 設定項目

### 提出物フォルダURL

Classroomが課題用に作成したGoogle DriveフォルダのURLを入力します。初期値ではサブフォルダも検索します。

### 課題の指示文またはURL

生徒へ提示した指示文を直接入力するか、次のようなURLを入力します。

- Googleドキュメント
- Googleスプレッドシート
- 閲覧可能なWebページ
- Google Drive上のテキストファイルまたはJSONファイル

### 配布データの説明またはURL

生徒へ渡した元データを説明する文章、または配布したGoogleスプレッドシート等のURLを入力します。配布データがない課題では `なし` と入力します。

配布データのスプレッドシートが提出物フォルダ内に置かれていても、そのファイルは生徒答案から自動除外されます。

### 採点基準またはURL

採点観点、重み、達成条件を文章で入力するか、それらを記載したファイルのURLを入力します。

例：

```text
合計10点
- 課題に合ったデータを選択している: 2点
- 関数や集計方法が適切である: 3点
- グラフの種類が目的に合っている: 2点
- 分析結果から具体的な考察を書いている: 2点
- 読みやすく整理されている: 1点
```

具体的な基準ほど、答案間で評価が安定します。

### 採点対象シート名

採点するシート名だけを、カンマ、読点、または改行区切りで指定します。

```text
データ分析, グラフ, 考察
```

指定していないシートはAIへ送信せず、採点もしません。指定シートが答案に存在しない場合は、結果の `不足シート` に記録され、先生の確認対象になります。

### その他

- `総点`: 初期値は10点
- `Geminiモデル`: 初期値は `gemini-3.5-flash`
- `結果ファイル名`: 実行日時を付けて新規作成
- `1シート最大読取セル数`: 巨大シートの読取上限
- `1答案最大文字数`: Geminiへ渡す答案の文字数上限
- `各参考情報最大文字数`: 指示・配布データ・採点基準の上限
- `評価のランダム性`: 初期値0.1。低いほど評価が安定

## 入力内容の確認

採点前に `自主課題AI採点 > 入力内容を確認` を実行します。

URLから読み取った内容を含め、Geminiへ渡す課題指示、配布データ、採点基準を `入力内容確認` シートで確認できます。URLの閲覧権限や内容に問題がある場合は、この段階でエラーになります。

## 採点の実行

`自主課題AI採点 > 提出フォルダをAI採点` を実行します。

各答案について、指定シートから次の情報を抽出します。

- セルの表示値
- 数式のR1C1表記
- グラフ種類
- グラフタイトル
- グラフの参照範囲

自由記述や答案内の文章は未信頼データとして扱い、答案に書かれた「満点にせよ」などの命令を無視するシステム指示をGeminiへ渡します。

## 結果スプレッドシート

### 採点サマリ

1ファイルにつき1行で、以下を出力します。

- ファイル名
- 得点、満点、得点率
- 総評
- 良かった点
- 改善点
- AI確信度
- 要確認
- 読み取ったシート、不足シート
- 答案の省略有無
- エラー
- 提出ファイルURL

### 採点詳細

採点基準の各観点について、得点、観点満点、判定理由、答案内の証拠を出力します。

### 実行情報

モデル、対象シート、文字数、実行日時などを記録します。

## AI採点について

- 模範解答との完全一致ではなく、採点基準に基づくAI評価です。
- 同じ答案でも、再実行時に小さな得点差が出る可能性があります。
- `要確認 = TRUE`、不足シート、答案省略あり、APIエラーの答案は先生が確認してください。
- 成績を確定する前に、先生が総評と根拠を確認してください。
- 生徒のスプレッドシート内容がGemini APIへ送信されます。学校や自治体の個人情報・生成AI利用ルールを確認してください。

## 再実行

このプログラムが作成した結果スプレッドシートには識別情報を付けます。同じ提出物フォルダで再実行しても、以前の結果ファイルは答案として採点されません。

## API仕様

Google公式の `models.generateContent` REST APIと構造化JSON出力を使用します。

- [Gemini API generateContent](https://ai.google.dev/api/generate-content)
- [Gemini API models](https://ai.google.dev/gemini-api/docs/models)
- [Structured outputs](https://ai.google.dev/gemini-api/docs/structured-output)
